Deauth

Menutup koneksi perangkat WiFi dengan mengirim frame deauthentication ke access point dan klien yang Anda pilih.

Deauth All (Adaptive ⭐)

Mode deauth dinamis: memindai ulang AP setiap 15 detik dan menyerang AP baru yang muncul. Cocok untuk skenario mobile (jalan kaki).

Beacon

Paket beacon untuk memalsukan access point. Dengan mengirim terus menerus, akan tampak seperti Anda membuat jaringan WiFi baru.

Probe

Probe request dikirim perangkat klien untuk mencari jaringan yang dikenal. Gunakan untuk membingungkan WiFi tracker.
